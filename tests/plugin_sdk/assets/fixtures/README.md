# 固定像素测试资源

这些微型图片由测试开发时使用 Pillow 生成并保存，运行测试不会重新生成它们。expected.json 中的期望值独立写定，未调用被测解码或权重合并算法计算。

RGB 两个像素为 (10,20,30)、(200,100,50)；dark 为 (1,2,3)、(4,5,6)。RGBA 的 alpha 为 128、255；opaque 为全 255。L 为 17、239；LA 对应 alpha 为 64、255。palette 使用同一 RGB 颜色及 128、255 透明度表。

外部 mask 为 128、64，和 RGBA 合并的固定期望为 64、64。zero/white 分别为全 0/255。JPEG 为 8×8 固定 (80,120,160)，quality=100、subsampling=0；因 JPEG 有损，测试允许单通道误差最多 1。
